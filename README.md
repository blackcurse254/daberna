# 🎲 پلتفرم آنلاین دبرنا لند VIP (Daberna Land VIP)
### نسخه رسمی Production • ۱۰۰٪ بازی رایگان و چندکاربره • معماری متمرکز بر سرور (Server-Authoritative)

---

## ۱. معرفی و اهداف پلتفرم

**دبرنا لند VIP** یک سامانه آنلاین و مدرن برای بازی دبرنای سنتی ۹۰ عددی ایرانی است که با زیبایی‌شناسی **Futuristic Gaming + Premium Lounge**، طراحی رابط کاربری چشم‌نواز با رنگ‌های *Midnight Navy*، *Electric Turquoise* و *Neon Violet* پیاده‌سازی شده است.

این پلتفرم بر اساس الزامات قانونی و اخلاقی **کاملاً رایگان** بوده و فاقد هرگونه تراکنش مالی، درگاه پرداخت، واریز، برداشت یا شرط‌بندی پولی است. تمام امتیازات در قالب **سکه دمو رایگان** و پاداش‌های ورود روزانه ارائه می‌شوند.

---

## ۲. پشته فناوری (Technology Stack)

- **Frontend:**
  - React 19 + TypeScript + Vite
  - Tailwind CSS 4 با متغیرهای گرافیکی و گرادیان‌های نئونی
  - Lucide React (آیکون‌های وکتور تعاملی)
  - انیمیشن‌های روان و ماتریس خوانای ۳×۹ دبرنا
- **Backend:**
  - Node.js + Express
  - Socket.IO برای ارتباط دوطرفه و همگام‌سازی بلادرنگ اعداد و چت
  - رمزنگاری پسورد با استاندارد صنعتی **Scrypt** و سشن‌های **HMAC-SHA256**
- **Database & ORM:**
  - PostgreSQL 16
  - Prisma ORM (فایل Schema و اسکریپت Migration در `prisma/`)
  - لایه ماندگاری دوگانه (`src/server/db.ts`) با ذخیره‌سازی داده‌ها و بازیابی لحظه‌ای
- **DevOps & Infrastructure:**
  - Docker & Docker Compose (`docker-compose.yml`)
  - Nginx Reverse Proxy با پشتیبانی پروتکل WebSocket (`nginx.conf`)
  - فیلترهای امنیتی Rate Limiting و هدرهای امنیتی ضد XSS و Clickjacking

## ۳. راهنمای نصب و راه‌اندازی سریع

### روش اول: استقرار با Docker Compose (توصیه‌شده برای سرورهای Production)

تنها با یک دستور کل استک شامل دیتابیس PostgreSQL، سرور Node و وب‌سرور Nginx راه‌اندازی می‌شود:

```bash
# ۱. کلون یا استخراج فایل‌های پروژه
git clone <repository_url>
cd daberna-land-vip

# ۲. ایجاد فایل تنظیمات محیطی از روی نمونه
cp .env.example .env

# ۳. اجرای کانتینرها در پس‌زمینه
docker-compose up -d --build
```
پس از چند ثانیه، برنامه روی پورت `80` (یا `3000` کانتینر) به نشانی `http://localhost` در دسترس خواهد بود.

---

### روش دوم: اجرای دستی در محیط توسعه (Local / Dev)

```bash
# ۱. نصب پکیج‌های پروژه
npm install

# ۲. اجرای سرور توسعه همراه با Vite و Socket.IO
npm run dev

# سرور روی آدرس زیر در دسترس خواهد بود:
# http://localhost:3000
```

## ۴. حساب کاربری پیش‌فرض مدیر (Admin)

جهت دسترسی به کنسول مدیریت عالی (Admin Panel):
- **نام کاربری:** `admin`
- **رمز عبور پیش‌فرض:** `AdminSecurePassword@90`
- **امکانات پنل:**
  - مشاهده کاربران و وضعیت آنلاین
  - مسدودسازی و رفع مسدودی کاربران
  - تغییر نقش بین بازیکن عادی و مدیر سیستم
  - اهدای سکه رایگان به کاربران
  - تنظیم تعداد سکه ورودی هر میز دبرنا
  - پایش لاگ‌های امنیتی سرور (Audit Trail)
  - گزارش خطاهای سرور و وضعیت عمومی سیستم

## ۵. تست‌های خودکار و تضمین کیفیت (QA & Security)

برای اجرای تمامی آزمون‌های امنیتی، اعتبارسنجی احراز هویت، کنترل دسترسی RBAC و عدم وجود روت‌های مالی:

```bash
node --test tests/production_verification.test.mjs
```

خلاصه آزمون‌ها:
1. اعتبارسنجی هش امن کلمات عبور با الگوریتم Scrypt و سالت تصادفی.
2. اعتبارسنجی توکن‌های نشست HMAC-SHA256 و جلوگیری از جعل توکن.
3. حفاظت از اندپوینت‌های مدیریتی (کد ۴۰۱ برای کاربران غیرمجاز و ۴۰۳ برای کاربران عادی).
4. بررسی حذف ۱۰۰٪ روت‌های واریز تتر، کارت‌به‌کارت و برداشت وجه.
5. اعتبارسنجی قوانین بازی دبرنا (تک‌خط، دوخط و دبرنای کامل) توسط سرور.
6. حفظ حریم خصوصی کاربران و عدم افشای شماره تلفن و رمز عبور در اندپوینت‌های عمومی.
